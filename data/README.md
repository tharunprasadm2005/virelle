# Data directory

## data/raw/ — REAL Food.com data goes here (never synthetic, never committed)

1. Download: https://www.kaggle.com/datasets/irkaal/foodcom-recipes-and-reviews (free Kaggle account).
2. Place the files as:
   - `data/raw/RAW_recipes.csv`
   - `data/raw/RAW_interactions.csv`
3. Alternative names from the same dataset family are auto-detected
   (`recipes.csv`, `reviews.csv`, …), but the `RAW_*` names are preferred.
4. Run `python scripts/inspect_dataset.py` — it prints actual columns/row counts
   instead of assuming a schema, and validates required columns.

Expected content (column names normalised case-insensitively, variants accepted):
- recipes: id/recipe_id, name, ingredients, tags, nutrition, minutes, description/steps
- interactions: user_id, recipe_id, rating (1–5), review text, date

## Measured stats (this workspace, `scripts/inspect_dataset.py` + preprocess report)

- `RAW_recipes.csv`: 522,517 rows; columns: RecipeId, Name, AuthorId, AuthorName,
  CookTime/PrepTime/TotalTime (ISO-8601, TotalTime used for minutes), DatePublished,
  Description, Images, RecipeCategory, Keywords, RecipeIngredientParts (R `c()` vectors),
  AggregatedRating, ReviewCount, Calories/FatContent/…/ProteinContent, RecipeServings,
  RecipeYield, RecipeInstructions.
- `RAW_reviews.csv`: 1,401,982 rows; columns: ReviewId, RecipeId, AuthorId, AuthorName,
  Rating, Review, DateSubmitted, DateModified.
- After preprocessing: 522,517 recipes, 854,948 interactions (rating-0 review-only rows,
  duplicates keep-last, and invalid recipe_ids removed; users ≥5 / recipes ≥3 activity
  filter; missing dates → median).
- Aspect coverage from real review texts: 25,599 users and 88,691 recipes with
  detected aspect signals (many reviews are too short/generic to yield aspects).
