# Virelle product guide

## Workflows
- **Onboard:** auth → diet/cuisines/priorities/avoids/max-time (+nutrition goals on
  profile) → cold-start picks labeled "Getting to know your taste".
- **Core loop:** discover/search → recipe → like/save/cook/rate/review → home
  re-ranks (stage flips to "personalized") → taste bars + evolution → plan week →
  shopping → cook again (cook mode records COOKED).
- **Pantry loop:** stock pantry → What-can-I-cook (coverage + taste) → missing →
  one-tap shopping → cook → mark available/used.
- **Import loop:** paste URL (Discover) → attributed import → collections → cook.

## Language rule
Product UI never shows: baseline, temporal, aspect, SVD, TF-IDF, NDCG, weights.
It shows: For You, Because you like, What's in your pantry, Your weekly plan,
My Taste. Research page keeps academic terms.
